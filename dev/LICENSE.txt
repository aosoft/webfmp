WebFMP
development by TAN-Y (https://github.com/aosoft)

著作権表示・ライセンス・利用条件

WebFMP は FMP.COM と、以下の第三者コードを使用しています。
各実行ファイル・コードには、それぞれの著作権と利用条件が適用されます。
第三者コードのライセンスを WebFMP 全体や入力データに一律に適用するものではありません。

FMP.COM 4.28u は同梱許可に基づき、未改変の実行ファイルを同梱・配信します。
曲データ、PCM データ、リズム WAV は本アプリに同梱しません。
ユーザーが読み込む曲データ・PCM データ・リズム WAV 等の利用条件は、各権利者の定めに従ってください。

使用する実行ファイル・コードの出典と変更内容

FMP.COM 4.28u
Copyright (C)1990-98 Osamu "Guu" Nagai
Theme of FMP — Composed & Arranged by KID
出典: FMP-SYSTEM Ver 4.28u

MAME NEC V30 Rust port
出典: https://github.com/mamedev/mame/tree/master/src/devices/cpu/nec
リビジョン: 8aeb28649e1be785a13cd06aa11ef033dfccac17
BSD-3-Clause。NEC V30 ネイティブ命令処理を Rust に移植しています。
MAME 全体の GPL コードやデバイス基盤は含めていません。

ymfm_oxide / ymfm
出典: https://github.com/neetandev/neetan
リビジョン: 98bbb4cc38c85ca23edf523ab7731fe38eb9d798
BSD-3-Clause。ローカルの Rust コアに、シーク時の波形出力を省略して状態を進める処理を追加しています。
FM のフィードバック、SSG、ADPCM の状態を保持し、通常の生成に戻る際に出力を復元します。

PPZ8 light unit / PMDWin
PPZ8L の C++ 実装を Rust に移植しています。PCM の復号・補間・ループ・音量・パンと、
PPZ8 の常駐 API に対応しています。PMDWin の独自の利用条件は、以下に全文を収録しています。

PDZF / Z8X
PDZFZ8XWin 2.0.1 の C++ 実装を Rust に移植しています。
COM 形式の API を Rust の型と trait に変更し、FMP ワークと PPZ8 に接続しています。
Windows 版は本アプリの開発者 TAN-Y によるものです。以下に元実装のクレジットを掲載しています。
